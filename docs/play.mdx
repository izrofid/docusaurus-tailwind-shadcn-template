### Manual Patch

1. **Download the Patch**  
    Click the "Download Patch" link above to get the `.bps` patch file.
2. **Get Your ROM**  
    Ensure you have a clean copy of `Pokémon Emerald (USA) v1.0`.
3. **Open a Patching Tool**  
    Use [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/) (web-based) or any compatible patching tool.
4. **Apply the Patch**
   - Select your ROM file as the "ROM file".
   - Select the downloaded `.bps` file as the "Patch file".
   - Click "Apply patch".
5. **Download the Patched ROM**  
    Save the output file (rename to `.gba` if needed).

You can now play Emerald Imperium on your favorite emulator!

## Troubleshooting

If you encounter any issues:

1. **Checksum Mismatch** - Ensure you're using a clean ROM of `Pokemon Emerald (USA) v1.0`
2. **Save Issues** - Make sure you're using a compatible emulator
